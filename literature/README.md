# Literature

PDFs are git-ignored — published papers are not redistributed here, and the Todd
review is an unpublished manuscript in preparation. Pull them from the lab Dropbox
`Literature/` folder.

| File | Reference | Why it matters |
|---|---|---|
| `Owusu-Yaw_FUSAAV9HD_Pharmaceutics_2024.pdf` | Owusu-Yaw et al., *Pharmaceutics* 16:710, 2024 | The direct predecessor. Same FUS rig (690 kHz, 10 ms bursts at 1 Hz), same AAV9-GFP construct, and the GFP-area quantification method this project needs to reproduce. Open access, CC BY. |
| `NickTodd_FUSAAVReview_FINAL_MolecTher.pdf` | Todd et al., *Molecular Therapy* (in preparation) | The lab's own review — how FUS-BBBO fits the wider CNS delivery landscape. **Unpublished; do not circulate.** |
| `Aryal_BBBReview_AdvDrugDeliv_2014.pdf` | Aryal et al., *Adv Drug Deliv Rev* 72:94, 2014 | Origin of the harmonic-emission controller idea: increase output until harmonic/subharmonic emissions appear, back off on broadband. The intellectual basis of `Harmonic Goal`. |
| `Kofoed_AAV9vsAAVPHP_MolecTherapy_2021.pdf` | Kofoed et al., *Mol Ther Methods Clin Dev*, 2021 | Capsid comparison — AAV9 vs. engineered PHP variants under FUS. |
| `Thevenot_AAVFUSBBB_HumanGeneTherapy_2012.pdf` | Thevenot et al., *Hum Gene Ther* 23:1144, 2012 | Early demonstration of AAV delivery across the FUS-opened BBB. |
